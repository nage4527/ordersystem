# 🥛 杏仁茶訂購系統

一個完整的線上訂購系統，支援多種商品、個別客製化選項、階段定價和自動訂單管理。

## ✨ 系統特色

- 🌐 **響應式網頁設計**：支援桌機與手機訂購
- 🤖 **自動化處理**：Google Apps Script + Google Sheets 整合
- 📍 **取餐地點**：常用擺攤地點選單 + 自定義地點輸入
- 💰 **階段定價**：杏仁茶 750ml 買越多越優惠
- 🍯 **搭配優惠**：杏仁茶 750ml 可與杏仁豆腐享組合價
- 🎯 **個人客製**：多杯商品可分別選擇甜度、溫度
- 📊 **即時管理**：店家可即時查看和管理訂單
- 🔒 **資料保護**：聯絡電話前導零完整保留

## 🛠️ 技術架構

- **前端**：HTML5 + CSS3 + Vanilla JavaScript
- **後端**：Google Apps Script (JavaScript)
- **資料庫**：Google Sheets
- **部署**：Google Apps Script Web App + 靜態網頁託管
